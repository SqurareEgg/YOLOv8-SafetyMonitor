# 📌 포트폴리오 요약

- **기간**: 2025년 ICT 한이음 드림업 공식 등록 기간 2025.4.1~10.31 (실제 개발은 5월 말~7월 초에 집중, 2025-07-08 최종 업로드)
- **인원**: 대학생 멘티 3명 + ICT 멘토 1명(가양전자)
- **담당 역할**: AI/YOLO 모델 파트 담당 → 이후 프론트엔드 작업까지 겸함

상세 배경(제안서 대비 구현 범위 조정, 트러블슈팅 등)은 [포트폴리오 상세 페이지](https://app.notion.com/p/3e9b0b7e2e7c8124a8c6c3da88be537c)에 정리했습니다.
원 제안서는 [`doc/가양전자 한이음드림업 수행계획서.pdf`](doc/가양전자%20한이음드림업%20수행계획서.pdf)에서 확인할 수 있습니다 (아래 "알려진 제한사항"에서 보듯 실제 구현 범위와는 차이가 있습니다).

## 1. 프로젝트 개요 (Overview)

YOLOv8 기반 실시간 객체 탐지 웹 애플리케이션입니다. 웹캠 스트리밍, 이미지/영상 업로드 분석을 지원합니다. 원래는 공사현장 안전모/조끼 미착용 탐지, 차량 번호판 인식 등 산업안전 특화 기능(원 프로젝트명 IOS)을 목표로 기획했으나, 아래 "알려진 제한사항"에 적었듯 실제로는 사람·차량 등 COCO 기본 클래스 탐지 데모 수준으로 축소되어 마무리됐습니다. (한이음 ICT 드림업용으로 제작)

## 2. 기술 스택 (Tech Stack)

- Python, Flask
- YOLOv8 (Ultralytics), OpenCV, PyTorch
- Jinja2 템플릿 + 바닐라 JS (실시간 스트리밍/설정 UI)

## 3. 핵심 기능 및 담당 구현 사항 (Key Features & Contributions)

- `/video_feed`: 웹캠 프레임을 실시간으로 YOLOv8 추론 후 MJPEG 스트리밍
- `/upload`: 이미지·영상 업로드 후 객체 탐지 결과 반환
- `/detection_log`, `/detection_log/export`: 탐지 기록 조회 및 CSV 내보내기
- `/settings`: 신뢰도(confidence)·NMS 임계값, 경보 대상 클래스(사람/안전모/조끼/차량/번호판) 설정

## 4. 알려진 제한사항 (Known Limitations)

- **안전모/조끼 탐지 미작동**: 설정 화면에 헬멧·조끼 탐지 임계값 슬라이더가 있지만, 실제 로드하는 모델(`yolov8n.pt`)은 COCO 80종 사전학습 모델이라 helmet/vest 클래스가 없습니다. 개발 초기 PPE 전용 데이터셋으로 커스텀 학습을 시도했으나 GPU 환경이 없어 CPU 학습 속도(에포크당 약 6분) 문제로 완주하지 못했고, 이후 시도한 공개 PPE 탐지 모델도 오탐이 많아 최종적으로 COCO 기본 모델로 되돌아갔습니다. 따라서 현재 코드에서 안전모/조끼/번호판 탐지는 실질적으로 동작하지 않습니다.
- **얼굴 인식 출입통제, 차량 번호판 인식(ALPR), 행동 예측, 클라우드 연동, 실시간 음성/푸시 알림** 등 최초 기획(수행계획서)에 있던 기능들은 구현되지 않았습니다.
- 테스트 코드 없음, 커밋 이력이 사실상 1회(2025-07-08)라 개발 과정의 변경 이력 추적이 어렵습니다.

## 5. 트러블슈팅 및 문제 해결 (Troubleshooting)

- 사전학습 가중치(`yolov8n.pt`, 6.5MB)와 `.idea` 설정 폴더가 소스코드와 함께 커밋되어 있던 것을 정리했습니다. `yolov8n.pt`는 Ultralytics 라이브러리가 최초 실행 시 자동 다운로드하므로 저장소에 포함할 필요가 없어 `.gitignore`로 제외했습니다.
- 레포 이름이 프로젝트 내용과 무관한 `IOS`로 되어 있던 것을 `yolov8-safety-monitor`로 변경했습니다.

## 6. 실행 방법 (How to Run)

```sh
pip install -r requirements.txt
python app.py
```

- 최초 실행 시 `yolov8n.pt` 가중치가 자동 다운로드됩니다.
- 기본 포트: `5000`

## 7. 성과 및 회고 (Results & Retrospective)

- 2025 ICT 한이음 드림업 창의도전형 프로그램을 특별한 수상 없이 수료했습니다.
- 대학 1학년 때 처음 참여한 외부 지원사업 팀 프로젝트로, YOLO 모델 학습·추론 파이프라인을 처음부터 직접 다뤄본 경험이었습니다. 동시에 GPU 없이 커스텀 모델을 학습하는 것이 얼마나 시간이 많이 드는 작업인지, 화려하게 설계한 문서와 실제로 동작하는 결과물 사이에 얼마나 큰 간극이 생길 수 있는지를 체감했습니다.
